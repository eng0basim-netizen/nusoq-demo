Security design for production

Prepared for Supabase after the MVP is approved.

Default security: Row Level Security on every project table and file bucket, workspace ownership on every record, per-member permissions, no public storage buckets, and no admin content browsing in the normal admin interface. Supabase connection comes after the MVP UI is stable.
